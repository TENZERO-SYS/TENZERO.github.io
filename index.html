04 / Operations log

Plan the recovery.

PHASE A

Before undocking

Review current intel, fit for the task, check escape routes, and set a clear abort condition.

PHASE B

On grid

Assess threats before approaching wrecks. Stay alert and don't let potential loot override survival.

PHASE C

After action

Log recovery value and losses, capture relevant evidence, and record lessons while details are fresh.

05 / Field manual

Recover smart. Extract alive.

Pre-flight checklist

1. Read recent intel.
2. Confirm roles and comms outside this site.
3. Set a loot threshold and withdrawal condition.
4. Check routes and alternate exits.

Report checklist

1. Include system and approximate EVE time.
2. Separate observation from hearsay.
3. Record value and losses where known.
4. Label uncertainty clearly.

Network principles

Be accurate, be useful, correct errors, protect personal information, and prioritize your capsuleer's survival.
